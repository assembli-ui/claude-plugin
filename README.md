# Assembli for Claude Code

Find and install React + Tailwind + shadcn/ui components and landing pages from Assembli (https://assembli-rho.vercel.app).

Run these inside Claude Code, one at a time:

```
/plugin marketplace add assembli-ui/claude-plugin
```

```
/plugin install assembli@assembli
```

Then run `/mcp`, pick assembli and choose Authenticate. Sign in in the browser and click Allow. Search works on any account; component source needs Assembli Pro and unlocks as soon as you subscribe.
